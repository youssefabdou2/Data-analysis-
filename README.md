# Data-analysis-
Data Visualization with Google Sheets
This project explores different chart types in Google Sheets to uncover patterns, correlations, and trends within various datasets. It demonstrates how to effectively use scatterplots, grouped and stacked bar/column charts, and line charts for visual storytelling.

🔍 Scatterplots: Relationship Between Two Numerical Features
Goal: Understand the relationship between median home size and median sales price.

Chart Type: Scatterplot

Features: Median Pending Square Feet (x-axis) vs Median Sale Price (y-axis)

Insights:

Positive correlation: As home size increases, so does the sale price.

Trendline with increased thickness and opacity helps highlight the linear trend.

Some high-priced counties do not follow the general trend — indicating other influencing factors.

Customizations included axis adjustments, gridlines for readability, and marker sizing (10px).

📊 Grouped Bar/Column Charts: Comparing Categories
Goal: Visualize the popularity of baby names across gender.

Chart Type: Grouped Bar Chart

Dataset: Top 10 male and female baby names (all-time totals)

Features:

Grouped by name rank and gender.

Gender represented using distinct colors (e.g., blue for male, green for female).

Axes formatted with commas for clarity in millions.

Gridlines refined for easier value estimation.

Insights:

Male names dominate in total count compared to female names, except for "Mary."

📉 Stacked Column Charts: Tracking Trends Over Time
Goal: Analyze unisex name trends over time (e.g., "Riley").

Chart Types:

Stacked Column Chart: Shows counts of male and female babies by year.

100% Stacked Column Chart: Shows proportions by gender.

Features:

Time on x-axis; gender counts on y-axis.

Color-coded by gender.

Subtle grid and legend placement improve clarity.

Y-axis changed to percentage in 100% stacked chart for distribution focus.

Insights:

"Riley" was primarily male before 1980s.

After 2003, more female babies named Riley than male.

📈 Line Charts: Visualizing Time Series Data
Goal: Examine trends over time for a specific name (e.g., "Ruby").

Chart Type: Line Chart (with Moving Average)

Features:

X-axis: Year

Y-axis: Baby count

Includes trend line for moving average

Gridlines (every 25 years, with 5-year increments)

Insights:

"Ruby" popularity rose, declined, and saw a resurgence post-2000s.

Moving average highlights cyclical trends.

1963 spike observed in raw count data, smoothed in moving average.

🛠 Chart Customizations Across All Types
Moved charts to separate sheets for clarity.

Added meaningful titles and subtitles.

Applied custom formatting to axes and numbers.

Adjusted gridlines and legend placement for better readability.

Used consistent color schemes across charts.

✅ Summary
This project demonstrates how to:

Visualize numeric relationships with scatterplots

Compare categories with grouped bar charts

Analyze part-to-whole relationships using stacked charts

Identify time trends using line charts

These visualizations help uncover hidden patterns, generate hypotheses, and communicate data-driven insights effectively.
